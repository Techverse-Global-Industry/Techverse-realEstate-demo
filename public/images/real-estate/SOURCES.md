## Important asset note

This generated project ships with lightweight local architectural stand-ins so the application has no missing-image errors and remains self-contained. Run `node scripts/fetch-unsplash-assets.mjs` in an internet-connected environment to replace the four free-image stand-ins with the brief's referenced Unsplash assets.

The supplied `LWwlbpsaIvI` skyscraper reference is an **Unsplash+** asset. It is intentionally not redistributed here. If you have the appropriate license, save the licensed export as `skyscrapers.jpg` in this folder.
